# Indian_Restaurants_Zomato_EDA
Exploratory Data Analysis of Indian Restaurants Dataset using Python

# 🍽️ Indian Restaurant Zomato – Exploratory Data Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on an Indian restaurant dataset containing information about restaurants listed on Zomato.

The objective of this analysis is to explore restaurant characteristics such as **ratings, pricing, locations, cuisines, popularity, localities, cost for two, and photo counts** and identify meaningful patterns in the data.

The analysis was performed using **Python, Pandas, Matplotlib, and Seaborn**.

---

## 📊 Dataset Overview

The dataset contains:

* **211,944 restaurant records**
* **26 columns**

The dataset includes information related to restaurant identity, location, cuisines, cost, ratings, votes, photos, and restaurant services.

### Important Columns

| Column                 | Description                          |
| ---------------------- | ------------------------------------ |
| `res_id`               | Restaurant ID                        |
| `name`                 | Restaurant name                      |
| `establishment`        | Type of restaurant establishment     |
| `city`                 | City where the restaurant is located |
| `locality`             | Restaurant locality                  |
| `latitude`             | Latitude of the restaurant           |
| `longitude`            | Longitude of the restaurant          |
| `cuisines`             | Cuisines served by the restaurant    |
| `average_cost_for_two` | Average cost for two people          |
| `price_range`          | Restaurant price range               |
| `aggregate_rating`     | Overall restaurant rating            |
| `rating_text`          | Rating category                      |
| `votes`                | Number of votes received             |
| `photo_count`          | Number of restaurant photos          |
| `delivery`             | Delivery-related information         |
| `takeaway`             | Takeaway-related information         |
| `opentable_support`    | OpenTable support information        |

## 💡 Key Insights

The analysis provides several observations about the restaurant dataset:

* The dataset contains **211,944 records across 26 columns**.
* Restaurant ratings vary across different price ranges.
* Chennai has the highest restaurant count among the top 10 cities identified.
* North Indian, Chinese, and Fast Food are among the most frequently occurring cuisines.
* Bangalore and Mumbai show the highest average ratings among the top 10 cities.
* Bawarchi has the highest number of votes in the popularity analysis.
* Civil Lines is the most frequently occurring locality.
* Ocean – The Private Dining Room in Mumbai has the highest average cost for two among the restaurants analyzed.
* Prankster, Tamasha, and 38 Barracks have some of the highest photo counts.
